# docs 说明

本目录存放 README 使用的界面截图。

| 文件 | 内容 |
| --- | --- |
| `screenshot-import.png` | 导入页：拖入一个多载具涂装包后自动识别出的载具列表 |
| `screenshot-manager.png` | 涂装管理页：国家筛选、卡片网格、图标、等级/权重、启用状态 |
| `screenshot-vehicle-popup.png` | 等级/权重浮层：三档不一致时补 AB / RB / SB 明细 |

## 截图来源与隐私

- 截图在隔离的临时沙盒（`%TEMP%`）中运行构建产物 `out/WTSkinManager.exe` 拍摄，使用合成/示例
  涂装包与示例 `UserSkins` 目录，不连接真实游戏账号。
- 截图中的游戏目录显示为 `Games\War Thunder`，是示例路径，不是任何人的真实安装位置。
- 截图拍摄时已关闭聊天窗口、文件选择对话框、桌面与其他第三方窗口；不包含用户名、绝对路径、
  Token、账号密码或其他个人信息。
- 截图中的《战争雷霆》载具名称与图标版权归权利人所有，仅用于功能说明，见 `assets/SOURCES.md`。
- 如需重新拍摄：在 `%TEMP%` 中准备沙盒安装目录与 `UserSkins`，用 DPI 感知的截图脚本只截取程序窗口，
  发布前逐张检查是否出现个人路径或第三方窗口。
